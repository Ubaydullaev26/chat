# Движок 3D-мультов v2

Кадры рисует three.js в браузере, а `three/capture.py` снимает их в Google Chrome без окна. Кадр вертикальный, 1080×1920.
Каждая сцена — чистая функция времени: кадр в момент t всегда одинаковый, поэтому кадры можно снимать в несколько потоков.

Стилей четыре: `toon` (Тун+), `soft` (Мягкое 3D), `clay` (Пластилин), `comic` (Комикс). Стиль задаётся в адресе,
сцена от него не меняется.

## Что нужно

- Google Chrome.
- Для съёмки кадров: Python 3.12+ и [uv](https://docs.astral.sh/uv/). Остальное uv поставит сам при первом запуске.
- Для видео: ffmpeg.

three.js и другие библиотеки уже лежат в `three/node_modules`, интернет для работы не нужен. Проверено на Mac с Apple Silicon.

## Посмотреть сцену в браузере

```bash
cd three
python3 -m http.server 8790
```

Открыть http://localhost:8790/index.html?ep=v2/t1&style=soft&view

Ползунок внизу двигает время, пробел запускает. `&draft` в адресе даёт быстрый черновик (одна проба на кадр),
`&t=6.5` открывает нужную секунду.

## Снять кадры и собрать видео

Команды запускать из корня архива:

```bash
uv run python three/capture.py --ep v2/t1 --style soft --stills 1.5,4.2,7.6 --out out/t1-stills
uv run python three/capture.py --ep v2/t1 --style soft --frames --out out/t1
ffmpeg -framerate 30 -i out/t1/%05d.jpg -c:v libx264 -pix_fmt yuv420p -crf 18 t1.mp4
```

Первая команда снимает три стоп-кадра в PNG, вторая — все кадры сцены в JPEG, третья склеивает их в mp4.

## Сцены

| Сцена | Что внутри |
|---|---|
| `v2/t1` | «Толик и ишак у горы», 9 с: три плана, основная тестовая сцена |
| `v2/tw` | «Склон», 12,6 с: лыжи, доска, трамплин, канатка |
| `v2/te` | эмоции: Толик и ишак проходят 15 эмоций, друг ещё 5, по 1,2 с на каждую |
| `v2/tc` | смотр героев на месте, камера — `&cam=wide`, `all`, `tolik`, `friend`, `donkey` или `side` |
| `v2/tk` | гардероб и позы катания, например `&who=tolik-ski&pose=carveL` |
| `v2/tp` | каталог зимних предметов, каждую секунду следующий |
| `v2/t0` | проверка всех стилей на простых фигурах |

В `capture.py` такие параметры передаются через `--query`, например `--query "cam=all"`.

## Своя сцена

Скопировать папку `three/v2/t1` под новым именем и править её `scene.js`. В нём две главные функции: `init(canvas)` строит
мир и героев, `render(t)` ставит всё на места в момент t. Запуск — `--ep v2/<имя папки>`.
Герои, мир, предметы и стили лежат в `three/v2/chars`, `world`, `props` и `styles`. Параметры адреса, устройство движка
и грабли описаны в `three/v2/README.md`.

В архив не вошли сборщик роликов с голосом и субтитрами и готовые сцены историй. Поэтому в `three/v2/README.md`
встречаются ссылки на `renderer/` и `vis/`, которых здесь нет.
