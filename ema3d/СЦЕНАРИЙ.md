# 3D-мультик для Reels: «Мадина и лечение без разреза» (ЭМА)

**Формат:** вертикальное видео 9:16 (1080×1920), 30 кадров/с, ~60 секунд
**Стиль:** мультяшное 3D (three.js): мягкий свет, тени, пролёты камеры
**Голос:** нейроголос Microsoft `ru-RU-SvetlanaNeural`, темп +8%
**Файлы:** `reels_ema_3d.mp4` (голос + музыка), `reels_ema_3d_golos.mp4` (только голос), `cover.png`

## Как пересобрать

```bash
npm install                                   # three.js
python3 voice.py ru-RU-SvetlanaNeural +8%     # voice.wav + timeline.json (pip install edge-tts)
node render.js 30 timeline.json video_silent.mp4
python3 music.py timeline.json voice.wav mix.wav
ffmpeg -i video_silent.mp4 -i mix.wav -c:v copy -c:a aac -b:a 192k -shortest reels_ema_3d.mp4
```
